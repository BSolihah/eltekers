# Panduan Pengguna: Admin Daerah (EIS Bogor)

Dokumen ini menjelaskan langkah-langkah penggunaan Dashboard Admin Daerah pada sistem EIS Bogor.

---

## 1. Login & Dashboard Utama
Setelah login menggunakan akun Admin Daerah, Anda akan diarahkan ke Dashboard Utama.
*   **Statistik**: Di bagian atas, Anda dapat melihat jumlah total Sasana, Peserta, Instruktur, dan Pengurus Sasana di wilayah Anda.
*   **Identitas Wilayah**: Nama wilayah Anda tertera di sebelah judul dashboard.

---

## 2. Manajemen Sasana (Tab: Daftar Sasana)
Menu ini digunakan untuk mengelola seluruh Sasana yang berada di bawah naungan wilayah Anda.

### A. Registrasi Sasana Baru
1. Klik tombol **"Registrasi Sasana Baru"**.
2. Masukkan **Nama Sasana**.
3. **Penting: Buat Akun Admin Sasana**. Isi Username dan Nama Lengkap Admin.
    *   *Catatan: Password awal untuk Admin Sasana baru adalah `sasana123`.*
4. Pilih lokasi lengkap (Provinsi, Kabupaten, Kecamatan, Desa).
5. Masukkan alamat lengkap dan koordinat Map (opsional).
6. Klik **"Registrasi Sasana"**.

### B. Mengedit Data Sasana
1. Klik ikon **Pensil (Edit)** pada baris sasana yang ingin diubah.
2. Anda dapat mengubah detail lokasi atau mengunggah **Foto Profil Sasana**.
3. Klik **"Simpan Perubahan"**.

### C. Reset Password Admin Sasana
Jika Admin Sasana lupa password mereka:
1. Klik ikon **Kunci (Reset Password)** pada baris sasana tersebut.
2. Klik "OK" pada kotak konfirmasi.
3. Password admin tersebut akan diatur ulang kembali menjadi `sasana123`.

### D. Menghapus Sasana
1. Klik ikon **Tempat Sampah (Hapus)**.
2. Konfirmasi penghapusan. *Peringatan: Menghapus sasana akan menghapus seluruh data terkait di dalamnya.*

---

## 3. Manajemen Slidebar / Carousel (Tab: Manajemen Slidebar)
Menu ini digunakan untuk mengatur gambar yang muncul di halaman depan (Landing Page).

### A. Menambah Slide Baru
1. Pilih file gambar (Saran: resolusi landscape seperti 1200x500px).
2. Masukkan **Judul Slide** dan **Deskripsi singkat**.
3. Atur **Urutan** (angka lebih kecil muncul lebih awal).
4. Klik **"Simpan Slide"**.

### B. Mengaktifkan/Menonaktifkan Slide
*   Gunakan tombol **Switch (On/Off)** di kolom Status untuk menampilkan atau menyembunyikan slide tanpa menghapusnya.

### C. Menghapus Slide
*   Klik ikon **Tempat Sampah** untuk menghapus slide secara permanen.

---

## 4. Keamanan Akun
Selalu pastikan untuk **Logout** setelah selesai menggunakan sistem untuk menjaga keamanan data wilayah Anda.
